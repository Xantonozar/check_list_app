# AGENTS.md — Muhasabat (মুহাসাবাত)

## Project Overview

**Muhasabat** is a daily Islamic self-accountability checklist app built with Flutter.
The app name means "self-reckoning" in Arabic/Bangla — the practice of evaluating one's daily deeds.

The entire UI is in **Bangla** (বাংলা). Arabic may appear only in Quran/Hadith references.

Users track mandatory and custom daily tasks, receive Salat-timed notifications,
and get weighted performance reports (daily, weekly, monthly) with charts and downloadable Google Sheets.

## Architecture

Follow **Clean Architecture** with **Feature-First** folder structure.

### Dependency Rule

```
Presentation → Domain ← Data
```

- **Domain** has zero Flutter/package imports. Pure Dart only.
- **Data** implements Domain interfaces. Talks to Firebase, APIs, local storage.
- **Presentation** uses Riverpod providers. Watches state, calls use cases.

### TaskModel

```dart
class TaskModel {
  final String id;
  final String title;            // Bangla
  final String description;      // Bangla
  final TaskPriority priority;   // mandatory | high | medium | low
  final bool isMandatory;        // true = cannot edit/delete
  final String? hadithRef;       // optional Arabic + Bangla translation
  final String? quranRef;        // optional Surah:Ayah reference
  final DateTime createdAt;
}
```

### DailyRecord

```dart
class DailyRecord {
  final String userId;
  final DateTime date;
  final Map<String, bool> completedTasks;  // taskId → done
  final double score;                       // weighted percentage
}
```

### TaskPriority Enum + Weights

```dart
enum TaskPriority { mandatory, high, medium, low }

// Scoring weights
const Map<TaskPriority, int> priorityWeights = {
  TaskPriority.mandatory: 10,
  TaskPriority.high: 7,
  TaskPriority.medium: 4,
  TaskPriority.low: 2,
};
```

Score formula:
```
score = (sum of weights for completed tasks) / (sum of weights for all tasks) * 100
```

## Notifications

6 daily notifications using `flutter_local_notifications` + `adhan` package.
Each notification is **individually toggleable (ON/OFF)** by the user via settings (saved in local preferences/database).

| # | Notification         | Trigger Time                          | Toggleable |
|---|----------------------|---------------------------------------|------------|
| 1 | ফজরের সালাত          | Fajr prayer time (adhan)              | Yes (ON/OFF)|
| 2 | যোহরের সালাত         | Dhuhr prayer time (adhan)             | Yes (ON/OFF)|
| 3 | আসরের সালাত          | Asr prayer time (adhan)               | Yes (ON/OFF)|
| 4 | মাগরিবের সালাত       | Maghrib prayer time (adhan)           | Yes (ON/OFF)|
| 5 | ইশার সালাত           | Isha prayer time (adhan)              | Yes (ON/OFF)|
| 6 | ঘুমের আগে যিকির     | User-configurable (default: 10:30 PM) | Yes (ON/OFF)|

### Implementation:
1. Use `geolocator` to get user's lat/lng.
2. Use `adhan` package to calculate today's prayer times locally.
3. Check user preference toggles (only schedule notifications that are turned ON).
4. Schedule enabled notifications via `flutter_local_notifications`.
5. Re-schedule every day at midnight or on app open.

## Google Sheets Weekly Report

### Flow (Single Master Spreadsheet):
1. User taps "ডাউনলোড" / "গুগল শিটে এক্সপোর্ট" button on the weekly report tab.
2. If not connected, prompt Google Sign-In (requesting Sheets + Drive scopes).
3. **First-time export**: Create a single Google Sheet in the user's Drive named `মুহাসাবাত — রিপোর্ট` and save its Spreadsheet ID in user profile/local storage.
4. **Subsequent exports**: Append the new week's report to the **existing** Google Sheet (adds a new worksheet tab named with the date range, e.g., `২৭ সেপ্ট - ৩ অক্টো`, or appends rows to the log), avoiding duplicate spreadsheets.
5. Worksheet structure:
   - Row 1: Headers (তারিখ, মোট টাস্ক, সম্পন্ন, স্কোর%)
   - Rows 2-8: Each day's data
   - Row 9: সাপ্তাহিক গড়

### Packages:
- `google_sign_in` for OAuth (requesting spreadsheets scope)
- `googleapis` (SheetsApi) to create/write sheets

## Scoring System

```
weighted_score = Σ(completed_task_weight) / Σ(all_task_weights) × 100
```

| Priority  | Weight |
|-----------|--------|
| Mandatory | 10     |
| High      | 7      |
| Medium    | 4      |
| Low       | 2      |

Example: User has 5 mandatory (50) + 2 high (14) + 1 medium (4) = total 68 points.
Completes all mandatory + 1 high = 50 + 7 = 57. Score = 57/68 × 100 = 83.8%
